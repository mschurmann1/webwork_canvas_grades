WeBWorK to Canvas homework grades

Choose the export that matches how your course grades homework. Files are read in your browser and never uploaded anywhere.

WeBWorK Written Work Export

For homework where each WeBWorK problem counts only when the written work for it earns credit on a Canvas rubric.

Files you will need

  • Canvas gradebook export
  • Written or upload rubric exports, one per homework set
  • WeBWorK scoring files ending in scr.csv, one per homework set
Open WeBWorK Written Work Export

WeBWorK Only Export

For homework graded entirely in WeBWorK. Scores can be entered as a percentage or as points out of the Canvas column.

Files you will need

  • Canvas gradebook export
  • One WeBWorK totals file covering every set
Open WeBWorK Only Export

The WeBWorK Written Work Export reads rubric files created by the Rubric Toolbar userscript. Set up Tampermonkey and the Rubric Toolbar before using it for the first time.
