WeBWorK to Canvas homework grades

Each WeBWorK problem score is multiplied by the matching rubric score (1 or 0), weighted by the problem value, totaled, and written into the Canvas column you choose as a percentage out of 100. Files are read in your browser and never uploaded anywhere.

⚠
Requires the Tampermonkey Rubric Export ToolbarThe written or upload rubric exports this tool reads are created by the Rubric Toolbar userscript, which runs in the Tampermonkey browser extension and adds an Export Rubric Scores button to Canvas SpeedGrader. Set up Tampermonkey and the Rubric Toolbar before using this tool.

Add your files

How to get the Canvas gradebook export
  1. In your Canvas course, open Grades from the course navigation.
  2. Click Export at the top right of the Gradebook.
  3. Choose Export Entire Gradebook. The .csv file downloads to your computer.

Make sure the homework assignments you want filled already exist in Canvas so their columns appear in the export. Open the file only if needed and do not save changes to it before loading it here.

How to get the written or upload rubric exports
  1. Find the written or upload assignment for the homework set and click the SpeedGrader option.
  2. Click the Export Rubric Scores button on the Rubric Toolbar.
  3. Repeat for each homework set you want to score. Load all of the rubric files together in the box below.

First time? Set up Tampermonkey and the Rubric Toolbar before following these steps.

Finish rating every problem on the rubric before exporting. A student whose rubric is only partly rated is left blank rather than guessed.

How to get the WeBWorK scoring files
  1. Click on Scoring Tools.
  2. Select the sets you want to export.
  3. Make sure that only Record scores for each set is selected.
  4. Click the Score selected set(s) and save to: button.
  5. You will see two files created per homework set. Download the first file, which ends in scr.csv, for each homework set.
  6. Upload those files in the WeBWorK scoring files box below.

Drop files onto a box or click it to browse. Each file is identified by its contents, so a file placed in the wrong box is sorted automatically.

Match sets to Canvas columns

Each WeBWorK set is paired with its rubric automatically by section number. Pick the Canvas column each percentage should fill, or leave a set unfilled.

Add a Canvas export and at least one WeBWorK file to see the sets.

How the percentage is calculated

Files and columns are paired by section number however they are named (Sec 2.4, Section 1.5, HW 2.4, Part 2, Pt II, Part B). When a section has more than one Canvas column, the WeBWorK or homework grade column is chosen over written work, upload, or rubric columns. Rubric rows are matched to Canvas by the abc123 ID when the export includes one, otherwise by full name, allowing names in a different order or with middle names and initials missing. Names that still cannot be matched are listed for you to pick by hand.

A student is only scored when every problem has an actual rating (0 or 1) in the rubric file. Blank ratings are never treated as 0: if the Canvas backup column has no score either, the student's cell is left blank so nothing is entered in Canvas. A rubric that is only partly rated is also left blank.

If a student has no row at all in the rubric file (or no rubric file is loaded for the set), the Canvas backup column is used instead: the student's WeBWorK percentage times their written or upload score divided by that column's points possible. For example, 90% in WeBWorK with 3 of 4 on the upload gives 67.50.

A 0 is entered in Canvas only when it comes from multiplying by a 0 rating in a rubric export: either the rubric zeroed out WeBWorK credit the student earned, or every problem was rated 0. A 0 that would come only from WeBWorK scores of 0, or from the Canvas backup column, is left blank and shown as "0 held" in the preview.

For each problem: WeBWorK score (0 to 1) × problem value × rubric points (1 or 0). The products are summed and divided by the total problem value for the set, then multiplied by 100 and rounded to two decimals. Students in Canvas with no WeBWorK record for a set are left untouched.
