WeBWorK to Canvas homework grades

Each WeBWorK problem score is multiplied by the matching rubric score (1 or 0), weighted by the problem value, totaled, and written into the Canvas column you choose as a percentage out of 100. Files are read in your browser and never uploaded anywhere.

How the percentage is calculated

Files and columns are paired by section number however they are named (Sec 2.4, Section 1.5, HW 2.4, Part 2, Pt II, Part B). When a section has more than one Canvas column, the WeBWorK or homework grade column is chosen over written work, upload, or rubric columns. Rubric rows are matched to Canvas by the abc123 ID when the export includes one, otherwise by full name, allowing names in a different order or with middle names and initials missing. Names that still cannot be matched are listed for you to pick by hand.

A student is only scored when every problem has an actual rating (0 or 1) in the rubric file. Blank ratings are never treated as 0: if the Canvas backup column has no score either, the student's cell is left blank so nothing is entered in Canvas. A rubric that is only partly rated is also left blank.

If a student has no row at all in the rubric file (or no rubric file is loaded for the set), the Canvas backup column is used instead: the student's WeBWorK percentage times their written or upload score divided by that column's points possible. For example, 90% in WeBWorK with 3 of 4 on the upload gives 67.50.

For each problem: WeBWorK score (0 to 1) × problem value × rubric points (1 or 0). The products are summed and divided by the total problem value for the set, then multiplied by 100 and rounded to two decimals. Students in Canvas with no WeBWorK record for a set are left untouched.
