Load one Canvas gradebook export and one WeBWorK totals file. Choose whether each WeBWorK set total is written as a percentage out of 100 or as a score out of the Canvas column's points possible, then pick the column to fill. Files are read in your browser and never uploaded anywhere.

Add your files

How to get the Canvas gradebook export
  1. In your Canvas course, open Grades from the course navigation.
  2. Click Export at the top right of the Gradebook.
  3. Choose Export Entire Gradebook. The .csv file downloads to your computer.

Make sure the WeBWorK homework assignments you want filled already exist in Canvas so their columns appear in the export. Exports with a single Student column and exports with separate LastName and FirstName columns both work.

How to get the WeBWorK totals file
  1. Click on Scoring Tools.
  2. Select every set you want to export. Hold Ctrl (Command on a Mac) to select more than one.
  3. Make sure Pad fields is unchecked.
  4. Click the Score selected set(s) and save to: button.
  5. Download the file ending in totals.csv.
  6. Upload that file in the WeBWorK totals file box below.

The totals file can include every section of the course. Only students in your Canvas export are used.

Drop a file onto a box or click it to browse. Each file is identified by its contents, so a file placed in the wrong box is sorted automatically.

Match sets to Canvas columns

What should go in the Canvas column?

Each WeBWorK set is paired with the Canvas column that shares its name and number, favoring WeBWorK homework columns. Sets with no credit for any of your students yet are left unfilled until you choose a column.

Add a Canvas export and a WeBWorK totals file to see the sets.

How the score is calculated

For each set, the student's WeBWorK total is divided by the set's total value. With Percentage selected, that fraction is multiplied by 100. With Score selected, it is multiplied by the points possible of the chosen Canvas column. Both are rounded to two decimals. For example, 24.8 out of 27 in WeBWorK gives 91.85 as a percentage, or 24.80 as a score in a Canvas column worth 27 points. If the file has no set value, the WeBWorK %score column is used instead.

Students are matched by the SIS Login ID in Canvas and the login ID in WeBWorK. A student with no matching login is matched by full name only when exactly one WeBWorK student has that name. Canvas students with no WeBWorK record are left untouched.

When the zero option is off, a student whose WeBWorK total is 0 is left blank instead of receiving a 0.
